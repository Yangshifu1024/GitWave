# 按 hunk 和变更行暂存

[产品路线图第 6 项](../../pm/core/03-roadmap.md#25-后续功能优先级)

## 使用流程

在 Changes 查看未暂存的文本 diff，选择某个 hunk 或其变更行加入 index。在已暂存侧选择相应内容，可将其移出 index。刷新后，两侧 diff 分别呈现剩余改动和已选内容；整个文件仍可使用原有的 stage / unstage 操作。

## 实现边界

部分暂存只修改 index，同文件内其他已暂存内容和工作区文件必须保留。以用户查看时的仓库、文件、diff 方向及内容识别这次选择；操作前后端重新生成 patch，比对预览令牌。未暂存侧比较 index 与工作区，已暂存侧只比较 HEAD 与 index；单独修改工作区不会使已暂存侧的预览失效。

仅支持已跟踪、状态为修改的常规文件（含可执行文件），前后文件模式相同。patch 必须是 UTF-8，大小至多 2 MiB，且不能出现缺少行终止符的标记。新增、删除、二进制或模式变化等其他情况仍可按整文件操作。

## 验证

在临时 Git 仓库内断言 index 的实际内容。覆盖多 hunk、单 hunk 的多行增删、已暂存与未暂存改动共存、部分取消暂存及读取后外部修改文件的情况；验证不支持的输入无法误触整文件操作。
