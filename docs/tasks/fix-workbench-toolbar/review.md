# 工作台工具栏审查

## ✅ 优点

Stash 单独成组，Fetch、Pull、Push 共用外框，各按钮直接接收点击。实际构建的 CSS 将命中区域限定在操作组，保留标题栏空白拖拽区。三个同步按钮继续调用原菜单动作，Pull、Push 仍先打开确认窗口。侧栏展开和折叠时都使用相同的中英文视图名称。

## 🔴 严重问题（必须修复）

本次变更未发现阻塞问题。

## 🟡 一般问题（建议修复）

审查中发现的文档偏差已修正。组件和布局规格现已区分零计数与禁用状态，旧 Working Copy 规格也指向当前「变更」入口。

## 🟢 优化建议（可选）

左侧文件管理器与终端沿用既有的提示组件。HeroUI 会在按钮外再创建一个可聚焦的提示触发器，键盘可能先停在外层。此次保留左侧交互；后续改进提示组件时可将提示与激活操作绑定到同一焦点。外部工具的目标路径、缺失仓库禁用条件和编辑器选择逻辑均与 main 一致。

## 📝 总体评价

已核对 Chromium 实测记录：1024px 和 1440px 下分别点击按钮中心与边缘时都只触发一次，悬停后仍能点击；键盘 Enter、Space、窗口拖拽空白区以及无仓库、同步中、detached HEAD、无变更和有冲突状态符合预期。独立运行的翻译一致性及状态区命中测试共 6 项通过。
