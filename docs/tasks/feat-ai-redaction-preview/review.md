# F019 独立代码审查

## ✅ 优点

预览和发送共用 Rust 端生成的脱敏快照。前端确认时提交一次性句柄，重试和备用供应商读取同一份消息。七个入口共用预览组件，取消和切换上下文都会释放句柄。

## 🔴 严重问题（必须修复）

首轮的三项严重问题已逐项复核。

| 首轮发现 | 修复及验证 |
|---|---|
| 普通邮箱后跟冒号会被当作 SSH 远端 | 已收窄远端识别规则。测试确认端口号和中文正文前的邮箱均脱敏，SCP 风格 Git 地址仍可读。 |
| diff 中独占一行的十六进制密钥会被当作 Git SHA | 已恢复编码行的凭证过滤。测试确认 64 位十六进制 diff 行整行脱敏，带标签的提交标识仍可读。 |
| 命令面板可能将旧请求的可执行意图显示在新的查询或仓库中 | 面板按 Workspace 和仓库重新挂载，查询或打开状态变化时使旧请求失效。延迟响应测试确认修改查询后，旧的建分支意图不会出现。 |

## 🟡 一般问题（建议修复）

- **预览阻塞 IPC 主线程，已修复。** `cmd_preview_ai` 已改为异步命令，通过现有的 `local_git_task` 在线程池执行本地 Git 读取。
- **reflog 解释显示在另一条记录下，记录级修复已核实。** 返回结果关联发起请求的记录，只有当前选中这条记录时才显示正文。
- **同一 Workspace 内切换仓库时，reflog 的选中记录和查询缓存沿用，已修复。** 已检查 `src/App.tsx` 的挂载键含 Workspace 和仓库，`ReflogPanel` 的查询键也含仓库。切换会重建面板状态，并按新仓库读取记录。此项通过代码复核，未单独运行交互测试。
