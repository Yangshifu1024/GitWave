# 两提交比较与路径历史

[产品路线图第 7 项](../../pm/core/03-roadmap.md#25-后续功能优先级)

## 对比提交

先将当前选中的提交设为比较基点，再选择同仓库的另一提交，打开比较视图。界面按“基点 → 当前选中提交”显示方向。以两棵提交树为边界呈现变更文件和所选文件的 diff。该操作是只读操作，可用于没有直接父子关系的提交。

## 查看路径历史

从当前选中的提交开始沿第一父提交链回溯。逐提交比较指定仓库相对路径在该提交和第一父树中的对象 ID 与文件模式。路径精确匹配，重命名前的旧路径需单独查看。每页至多扫描 128 个提交；即使当页没有命中，只要还有父提交就可继续。点击匹配项可回到提交图定位。

## 验证

用包含非相邻提交、同名文件、文件删除和重命名的历史检验比较方向与路径匹配。检查分页边界上的匹配、空结果以及切换仓库后迟到的响应。
