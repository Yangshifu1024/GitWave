# History 提交搜索与定位审查

基于 `origin/main`（`9c39bff`）核对 History 工具栏、搜索弹窗、分页与定位路径、中英文文案及任务计划。

## ✅ 优点

- 搜索直接使用当前 Workspace 和仓库的提交分页。已核对 Rust 端索引包含完整 SHA、完整提交说明、作者姓名和邮箱，查询和索引均转小写。
- 首批未命中时仍能沿游标查找更早的提交。后续页读取失败时可以重试，已找到的提交保持可见。查询、工作区和仓库变更时会隔离旧请求。
- 选中结果后，详情和提交图使用同一完整 SHA。若提交尚未载入，提交图会继续翻页并在定位后停止。History 搜索没有 AI 或 checkout 调用。

本轮未发现阻塞合入的严重问题。

## 🟡 一般问题（建议修复）

首轮发现正常分页只显示继续按钮，缺少已扫描条数和快照大小。已修复并复核，非空快照均展示当页累计扫描数和快照总量，截断说明独立显示。组件测试覆盖首批零命中时显示已扫描 2,000 / 3,000 条并能继续搜索。
