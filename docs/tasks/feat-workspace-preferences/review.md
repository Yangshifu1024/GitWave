# 仓库离线偏好与命令面板快捷键审查

## ✅ 优点

AI 供应商选择按实际任务仓库合并离线规则。Workspace 或仓库任何一方要求离线时，均会执行离线策略。预览确认发送和直接生成走同一处检查。

## 🔴 严重问题（必须修复）

原先修改单个离线开关会反序列化并重写整个设置对象，可能删除此版本不认识的设置字段。已改成 SQLite 只更新目标 Workspace、仓库的一项 JSON 属性，旧数据继续继承。回归测试包含未知设置字段及同级已有的主题覆盖。

## 🟡 一般问题（建议修复）

快捷键曾在所有平台接受 Ctrl 和 Meta 任一修饰键，而且部分 macOS 布局会把 Option+K 报告成死键。匹配器现在与设置页显示的平台修饰键一致，并识别 Option 组合对应的 K 键。切换仓库后，上一仓库写入失败的信息也不会出现在当前仓库的设置项中。

## 🟢 优化建议（可选）

本轮无额外建议。

## 📝 总体评价

两组快捷键与命令面板前端测试共 8 项通过，覆盖重启恢复、非法配置回退、平台修饰键、Option 死键、重复按键及输入法组字。

两项 Rust 回归通过，分别验证 SQLite 更新和清除仓库选项时完整保留其他字段，以及发送 AI 请求时按实际任务仓库读取规则、Workspace 离线设置优先。
