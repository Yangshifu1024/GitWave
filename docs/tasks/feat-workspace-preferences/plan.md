# Workspace、仓库偏好与快捷键

[产品路线图第 9 项](../../pm/core/03-roadmap.md#25-后续功能优先级)

## 配置作用域

首批支持 AI 离线模式。仓库可以继承 Workspace 设置，也可以单独要求离线。Workspace 强制离线时，仓库设置无法重新启用云端 AI；Workspace 允许联网时，仓库仍可要求离线。清除仓库覆盖后重新继承 Workspace 的当前值。旧数据默认继承。

## 编辑快捷键

在设置的常规页选择打开命令面板的快捷键，选择保存在本机，适用于所有仓库。可选默认的 Cmd/Ctrl+K，以及带 Shift 或 Alt 的两种组合。选回默认项即恢复原键位。其他命令及 vim mode 单独评估。

## 验证

覆盖缺少历史配置、只设置 Workspace 值、仓库覆盖及清除覆盖的情况。在两个仓库间切换并重新打开应用，验证显示的值与实际行为相符。验证修改后仅所选组合触发，输入法组字或按住键重复触发时保持原状态。
