# 会话操作记录与共用命令入口

[产品路线图第 8 项](../../pm/core/03-roadmap.md#25-后续功能优先级)

## 回看本次会话

首批记录 fetch、pull、push 和工作区的 stage、unstage、discard、ignore、commit。用户可从底栏回看本次会话最近 200 条记录的时间、动作、目标仓库及结果。当用户在任务执行期间切换仓库，结果仍属于发起操作的仓库。记录应足够定位操作，同时避免保存凭据和输入正文。

## 复用操作入口

工具栏和命令面板中的 fetch、pull 和 push 交给已有菜单操作处理。Pull 与 push 打开对应确认窗口；设置和命令面板沿用现有入口。各入口沿用仓库选择、可用状态和确认流程。记录入口触发后的实际结果，同一操作只产生一条对应记录。

## 验证

从覆盖到的不同入口触发同一动作，验证目标和执行次数。覆盖成功、失败、切换仓库以及底栏临时提示消失后回看记录。关闭再启动应用时，以新的会话开始记录。
