# GitWave 原生 UI 迁移

状态：首个原生预览。分支 `feature/nsgo-native-ui`，对照基线 `004c9f4`（v0.11.0）。

## 目标

用 Go 和 NSGo 原生视图复刻当前 GitWave 的画面和交互。沿用 Rust 的 Git、持久化和凭证模块。以当前实际能触达的 UI 为清单来源，覆盖主流程及加载、空态、失败、确认和恢复。完成全量复刻验收后再讨论优化。

## 顺序

1. 自绘标题栏、工作台布局、History 和 diff。还原 40 点标题栏、macOS 窗口按钮留白、工具栏分组、32 点仓库标签和底栏、三个可调分栏。复用 Rust 历史分页、提交详情和有限尺寸的 diff 预览。对照 28 点行高、18 点图泳道、refs 列、文件列表、unified/split diff 及选择行为。
2. Workspace、Changes 和 Git 操作。对照仓库级会话、状态恢复、写操作确认、进度及取消。迁移冲突、interactive rebase、stash 和其余 Git 工具。
3. 设置、AI、原生菜单、命令面板、关于及更新。验收中英双语、主题、键盘、无障碍及各平台系统控件。
4. 全量验收及发布切换。对照同平台、窗口大小、主题、语言和真实仓库。演练旧版数据、凭证、安装、更新和回退，再启用新的默认构建。

## History 验证

- 同一测试仓库对照线性、分支及合并历史，检查分页、滚动、节点、refs、提交选择和文件切换。
- 对比新增、删除、替换、二进制、超大文件，以及中英文路径和内容。切换仓库或提交后，之前请求的结果不得写回当前视图。
- 三端核对浅色、深色、键盘、分栏和窗口缩放。使用[现有性能预算](../../tech/engineering/00-overview.md#性能预算)测量 macOS 冷启动、1 万 commit 历史与 1 MB diff。

## 原生预览

`make native-dev` 构建 Rust 子进程并打开预览。用 Workspaces 菜单或空态按钮选择已有本地仓库。测试入口为 `make native-test`，使用临时 Git 仓库覆盖目录选择、旧游标恢复、提交和文件切换、文本/图片 diff 及标题栏边界。

首版可预览 History 与 diff。工作区持久化、其余工具栏动作、完整 refs/侧栏与命令面板仍需复刻。Windows 和 Linux 的布局覆盖目前来自模型测试和交叉编译。Linux 自绘标题栏的窗口边缘缩放、macOS 双击标题栏与旧版即时缩放的行为差异，需要继续实机对照。全量 UI 和性能验收属于发布切换门槛。

现有界面见[工作台设计与交付记录](../../design/09-workbench-redesign.md)和 [v0.11.0 截图](../../../assets/gitwave-screenshot.png)，现有进程和用例边界见[架构](../../tech/architecture/00-overview.md)。
