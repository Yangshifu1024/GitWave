# 终端与编辑器选择审查

## ✅ 优点

首次点击展开已安装工具；选定后名称按钮直接启动，箭头独立打开菜单。两类工具分别保存偏好，启动期间禁止重复操作。Chromium 验证记录覆盖 900、1024、1440px 下的实际点击，以及键盘激活、语言切换和重载恢复。

## 🔴 严重问题（必须修复）

初版在子进程创建后立即记录成功，即使启动器随后立即报错。修复后，系统中继检查退出状态，长驻程序检查最初 200 毫秒内的退出结果。已用实际子进程验证早期非零退出会传回错误，前端保留上次成功的选择。

## 🟡 一般问题（建议修复）

已核对三项修复：编辑器将相对仓库路径转为绝对路径；Windows 的命令提示符和编辑器批处理入口对 UNC 共享目录使用 `pushd`；工具发现和路径检查通过工作线程执行。Linux 的 PATH 别名去重与 Flatpak 导出均有回归覆盖。

## 🟢 优化建议（可选）

共享的 PATH 查找函数已限定在使用它的平台编译。

## 📝 总体评价

独立运行的 Rust 测试 3 项、工具选择组件及翻译一致性测试 11 项全部通过。工作目录测试覆盖空格、中文与特殊字符。Windows 与 macOS 的实际桌面启动仍需在对应系统验证。

紧凑菜单复核通过。样式仅作用于终端和编辑器菜单；Chromium 实测常规选项高 28px，长名称在 240px 上限内完整换行，当前标记可见，点击其他选项能正常切换。
