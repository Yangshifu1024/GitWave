# 冲突处理与交互式 rebase

[产品路线图第 5 项](../../pm/core/03-roadmap.md#25-后续功能优先级)

## 解决冲突

直接在工作台主区显示冲突文件与编辑器。文件列表标出未保存编辑与本次已标记解决的路径。清楚区分编辑缓冲区有改动、文件已标记解决，以及整个操作仍在进行。根据后端状态给出下一步；存在孤立 index 冲突时，只提供该状态可执行的动作。

## 整理 rebase 待办

在现有 todo 对话框内，逐行提供可用键盘操作的上移和下移按钮，保留拖拽及已有序列校验。rebase 暂停编辑时，工作台显示暂停提示和继续、放弃暂停的操作。

## 验证

用临时仓库覆盖真实 merge 冲突、标记解决后仍需完成的 merge，以及 rebase 的中止或暂停状态。验证关闭或切换目标时对未保存编辑的保护，并检查键盘上移或下移首尾项的边界。
