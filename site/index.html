GitWave

A local-first Git client with AI collaboration.

Full-featured visual Git for everyday work — workspaces, history graph, diffs and branches — with AI assistance on your terms.

Download for macOS View on GitHub

Also available for Windows and Linux — no system Git required.

Everything a Git client should do

Built as a native-feeling desktop app, powered by vendored libgit2 — not a shell around your system Git.

Workspaces

Group repositories into workspaces with draggable repo tabs and per-workspace AI context. A workspace is an abstraction — not a directory on disk.

Working copy

Stage, unstage, discard and ignore with confidence. Conventional-commit type chips and AI-assisted messages make committing fast.

History & branches

A fork-style commit graph with blame, reflog and tags. Create, switch, rename and delete branches; double-click a remote branch to create its tracked local branch and switch to it; push and pull with confirmation across any remote, plus ahead/behind counts. Right-click menus on commits, badges and branches — checkout, cherry-pick, revert, reset, tracking and more. Ref badges merge a tracked remote into a single synced badge, and the graph runs on a nine-color lane palette.

Diff viewer

Side-by-side and unified views with Shiki syntax highlighting, per-hunk operations and rich file-level context.

AI collaboration

Bring your own key. Explain commits, draft PR descriptions, assist commit messages — diffs stay local unless you send them to your chosen provider.

Batteries included

Stash, interactive rebase, worktrees, submodules, LFS, SSH key management, repo health checks, a native macOS menu bar, a command palette, in-app auto-updates, an in-app auth prompt for remotes that challenge for credentials, time-boxed cancellable network syncs, adjustable UI / monospace font sizes and a Chinese / English interface — all in one app.

Private by design

GitWave is local-first by architecture: diffs never leave your machine unless you explicitly send them to the AI provider you configured. HTTPS credentials go through your git credential helper, SSH through your configured keys.
