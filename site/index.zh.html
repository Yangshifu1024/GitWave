GitWave

本地优先、可自主接入 AI 的 Git 客户端。

功能完整的可视化 Git，覆盖日常工作——工作区、提交历史图、diff 和分支——AI 辅助方式由你决定。

下载 macOS 版 怎么开始 在 GitHub 上查看

同时提供 Windows 和 Linux 版本——无需安装系统 Git。

Git 客户端该做的事，它都做了

原生质感的桌面应用，底层是随应用打包的 libgit2——不是套在你系统 Git 外面的一层壳。

工作区

把仓库归入工作区，仓库标签可拖动，AI 上下文按工作区隔离。标签栏溢出时可用鼠标滚轮横向滚动，并让当前标签始终留在视野里。可一次添加多个本地仓库——重复项和不可用路径会被报告出来，但不会让整批添加失败。工作区是一种抽象——不是磁盘上的目录。

工作副本

放心地暂存、取消暂存、丢弃和忽略。Conventional Commits 类型标签，加上 AI 辅助撰写的提交信息，让提交变快。

历史与分支

分叉式提交历史图，带 blame、reflog 和标签，滚动很长的历史也依然顺滑。分支操作一应俱全：双击远程分支即可把它检出为本地跟踪分支，提交和引用上都有右键菜单——检出、cherry-pick、revert、reset 等等。可在完整的远程分支列表里设置上游跟踪，侧边栏会自动展开到你检出的那个分支。

diff 查看器

并排和统一两种视图，改动行内做字符级高亮，图片支持并排 diff（旧图对新图，覆盖常见图片格式——未暂存的改动，新图一侧反映工作区里的实时内容），可按 hunk 逐块操作，并附带丰富的文件级上下文。

AI 协作

自带密钥。解释提交、起草 PR 描述、辅助撰写提交信息——除非你主动发给所选的模型服务商，否则 diff 始终留在本地。

开箱即用

贮藏（作用范围是当前仓库——每个条目都会打开详情窗口，列出文件清单和 diff，操作都是带文字的按钮；apply 前会先检查工作副本是否有未提交的改动，drop 前会先确认）、交互式变基、worktree、子模块、LFS、SSH 密钥管理、命令面板、自动更新、按可配置间隔让工作区内每个仓库保持最新的后台自动刷新，以及感知系统代理的网络。一键即可在当前仓库打开文件管理器、终端或检测到的代码编辑器（VS Code / Zed / VSCodium）——全都在同一个应用里。应用菜单和操作栏共用一个单行自定义标题栏，macOS 的红绿灯按钮与 Windows / Linux 的窗口控件都清晰可见。
