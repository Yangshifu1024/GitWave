新手指南

从空窗口到第一次推送

GitWave 是可视化 Git 客户端。这份指南带你看清窗口里每天都会用到的部分，以及让仓库从本机走到远程的四个动作。

大约 10 分钟 · macOS、Windows、Linux

1 · 工作区与仓库 2 · 界面地图 3 · 主路径四步 4 · 克隆远程仓库 5 · 常见卡点

工作区与仓库

工作区不是一个磁盘目录。它是一个抽象的分组，把你要放在一起处理的仓库装进来——后端和前端、同一个库的三个版本，或者一个仓库和它的子模块。这些仓库在文件系统上没有任何关系。

用标题栏最左侧的下拉切换工作区。在一个工作区里，每个仓库是一个标签页：点标签切换当前仓库，拖动标签调整顺序，标签放不下时用鼠标滚轮横向滚动，当前标签始终留在可见区域。

你看到的一切都属于当前仓库——提交历史图、左侧栏、工作副本、AI 上下文。切换标签，它们一起跟着切换。

可以一次添加多个仓库。重复的路径和不可用的路径会被逐个报告出来，这一批里其余的仓库照样添加成功。

界面地图

标题栏上有应用菜单、工作区下拉、同步动作（获取、拉取、推送），以及打开工作副本窗口的变更按钮。

  • 左侧栏——可折叠的分组：分支、标签、贮藏、远程、子模块、worktree，还有工作副本入口。检出某个分支时，左侧栏会自动展开到它。
  • 中间——提交历史图：每个提交一行，用分叉样式绘制，滚动长历史时合并和并行分支依然看得清。右键提交可以检出、cherry-pick、还原、重置等操作。
  • 右侧——选中提交的详情：提交信息、作者，以及这次提交改动的文件列表。点文件看 diff。

主路径四步

这四步就是日常循环：把仓库放进来、读一个提交、提交你的改动、推送。

  1. 1

    把仓库放进来

    主区为空时，GitWave 会直接给出三个按钮：克隆远程仓库、初始化新仓库、添加已有本地仓库。点添加已有本地仓库，选中已经含有 .git 目录的文件夹，仓库就会作为一个标签页打开。一次可以选多个文件夹。

    这三个动作在应用菜单的仓库菜单里也有。macOS 上应用菜单在系统菜单栏，Windows 和 Linux 上在窗口顶部的菜单栏。

  2. 2

    读一个提交

    在历史图里点任意一行。右侧详情会填上这次提交的信息、作者和改动的文件；点文件打开它的 diff。可以在并排和统一两种视图之间切换；只想处理一个文件里的某一段改动时，用按 hunk 划分的操作。

  3. 3

    提交你的改动

    用你习惯的编辑器改文件，GitWave 会随文件变化刷新工作副本。标题栏的变更按钮打开工作副本窗口，未暂存和已暂存的文件分列两侧：把属于这次提交的文件暂存，写提交信息，然后点提交。

    约定式提交的类型标签（feat、fix、docs ……）会自动加在信息前面；配置好服务商密钥后，生成按钮会根据已暂存的 diff 起草一条提交信息。

  4. 4

    推送

    标题栏的推送按钮会弹出确认框。这个对话框只提交三项：目标远程、是否推送这个提交上的标签、是否强制推送。确认远程和推送到的分支后推送即可。它不负责设置上游——如果这个分支还没有上游，去左侧分支列表里右键该分支，选跟踪分支…，挑一个它要跟踪的远程分支。获取和拉取按钮就在推送按钮旁边。

克隆远程仓库

克隆是另一种把仓库放进来的方式。用空主区的克隆远程仓库按钮，或者应用菜单仓库里的同一项。粘贴远程地址、选本地目录，GitWave 会获取这个仓库并把它作为一个标签页打开。地址栏同时接受 HTTPS 和 SSH 地址，检出的是远程的默认分支。

HTTPS。第一次需要凭据的操作——通常是第一次推送或获取——会在应用内弹出登录窗口。你输入的内容交给系统的凭据管理器（macOS 是钥匙串，Windows 是凭据管理器，Linux 是 libsecret），之后的操作就不再询问。

SSH。如果远程地址以 git@ 开头，GitWave 使用 ssh-agent 里的密钥——和 git 命令行用的是同一批。打开设置 → SSH 密钥可以查看这些密钥；添加 SSH 密钥可以把另一把私钥注册进去。推送前可以用测试 SSH 连接先和主机验证一次。

常见卡点

第一天最容易卡住的五件事，以及各自在哪里解决。

刚初始化的空仓库提交不了

新建的仓库里还没有任何提交，也没有文件，所以历史图显示的不是提交列表，而是创建第一个提交按钮。点这个按钮会打开标题为这是一个空仓库的弹窗，里面解释了为什么现在提交不了，并给出克隆远程仓库，把已有项目拿进来。想自己完成第一个提交，就先往工作目录里放文件，再打开工作副本窗口暂存并提交。

登录窗口反复出现

GitWave 通过系统的凭据管理器保存 HTTPS 凭据。如果每次推送都重新弹出，说明凭据没有存下来——重新输入一次，并确认系统的凭据管理器已解锁、正在运行。

SSH 要求输入口令，或者推送被拒绝

打开设置 → SSH 密钥。这个分区列出 ssh-agent 里的密钥，添加 SSH 密钥可以把另一把私钥注册进去，测试 SSH 连接只和主机通信，不碰你的仓库。用 git@ 地址推送被拒绝，通常是主机上还没有你的公钥。带 passphrase 的密钥不能在这里添加——先在终端执行 ssh-add。

合并或变基停在冲突上

冲突文件会出现在工作副本和合并冲突面板里。在面板里打开文件，对照两边的改动，逐个文件选择保留哪一边，然后在同一个面板里继续合并或变基。

界面语言

设置 → 通用可以在中文和 English 之间切换界面语言。本指南的截图和页面语言一致：如果你的窗口和图片不一样，先切换应用语言再对照。
