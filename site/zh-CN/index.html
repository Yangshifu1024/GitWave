GitWave

本地优先、AI 协作的 Git 客户端。

面向日常工作的全功能可视化 Git——工作区、历史图、diff 与分支——AI 协作方式由你掌控。

下载 macOS 版 在 GitHub 查看

同样支持 Windows 与 Linux——无需系统 Git。

一个 Git 客户端该有的，它都有

以原生质感桌面应用的方式构建，内置 libgit2 驱动——不是套在系统 Git 外面的一层壳。

工作区

将仓库组织进工作区，支持仓库 Tab 拖动排序与按工作区隔离的 AI 上下文。Workspace 是抽象概念——不是磁盘上的目录。

工作副本

从容地暂存、取消暂存、丢弃与忽略。conventional commit 类型徽标与 AI 辅助信息让提交更快。

历史与分支

Fork 风格提交图，附 blame、reflog 与 tag。新建、切换、重命名、删除分支；带确认与 ahead/behind 计数的 push 和 pull，可面向任意 remote。提交、徽章与分支均支持右键菜单——检出、拣选、撤销、重置、跟踪上游等。

Diff 查看器

分栏与统一视图、Shiki 语法高亮、按 hunk 操作，以及丰富的文件级上下文。

AI 协作

自带 key。解释 commit、起草 PR 描述、辅助 commit message——除非你主动发送给所选供应商，diff 不离开本机。

开箱即用

stash、交互式 rebase、worktree、子模块、LFS、SSH 密钥管理、仓库健康检查、macOS 原生菜单栏、命令面板、应用内自动更新、限时可取消的网络同步、界面 / 等宽字体大小独立可调与中文 / English 双语界面——一个应用全搞定。

隐私内建于架构

GitWave 从架构上就是本地优先的：除非你显式把 diff 发送给你自己配置的 AI 供应商，否则 diff 永远不离开你的电脑。HTTPS 凭证走你的 git credential helper，SSH 走你配置的密钥。
